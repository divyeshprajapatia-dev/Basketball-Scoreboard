# 🏀 Basketball Scoreboard  
A simple and clean digital scoreboard built using **HTML, CSS, and JavaScript**.  
It allows users to track scores for two teams, increment points, and reset the game.

---

## 🎯 Features

- 🎮 **Score tracking for Home & Guest teams**  
- ➕ Add **+1**, **+2**, or **+3** points  
- 🔁 **New Game** button to reset scores  
- 💡 Retro digital-style display  
- 🎨 Styled with pure CSS (no frameworks)  
- ⚡ Lightweight and fast — runs in any browser  

---

## 🛠️ Tech Used

- **HTML** – Structure  
- **CSS** – Styling, retro scoreboard design  
- **JavaScript** – Score logic & interactivity
